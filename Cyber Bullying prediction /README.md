# Cyber Bullying Prediction 🛡️

## 📌 Overview

This project focuses on predicting whether a given text contains
cyberbullying content using machine learning techniques.

It analyzes textual data and classifies it into bullying or non-bullying
categories.

------------------------------------------------------------------------

## ⚙️ Features

-   Text preprocessing and cleaning
-   Dataset handling using CSV file
-   Machine Learning model for classification
-   Jupyter Notebook implementation for easy understanding

------------------------------------------------------------------------

## 📂 Project Structure

    Cyber-Bullying Prediction/
    │── cyber_bullying.ipynb   # Main notebook
    │── Formspring.csv         # Dataset

------------------------------------------------------------------------

## 🚀 How to Run

1.  Clone the repository

2.  Install required libraries:

        pip install pandas numpy scikit-learn matplotlib

3.  Open the notebook:

        jupyter notebook cyber_bullying.ipynb

------------------------------------------------------------------------

## 📊 Dataset

The dataset used is **Formspring dataset**, which contains
user-generated text labeled for cyberbullying detection.
